## 🚀 使用说明

### 本地运行
```bash
cd docs-site
pip install -r requirements.txt
mkdocs serve
```

访问 http://127.0.0.1:8000 查看网站

### 构建部署
```bash
mkdocs build
# 生成的静态文件在 site/ 目录
```
