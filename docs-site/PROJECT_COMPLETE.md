## 🚀 如何使用

### 1. 本地预览
```bash
cd docs-site
source venv/bin/activate
mkdocs serve
```
然后访问 http://127.0.0.1:8000

### 2. 构建网站
```bash
cd docs-site
source venv/bin/activate
mkdocs build
```
静态文件将在 `site/` 目录中生成。

### 3. 一键部署
```bash
cd docs-site
./deploy.sh
```
