# 觉察之美：身体美学与医美决策心理学 - 网站版

这是《觉察之美：身体美学与医美决策心理学》一书的MkDocs网站版本。

## 快速开始

### 1. 安装依赖

```bash
# 创建虚拟环境（推荐）
python -m venv venv
source venv/bin/activate  # Linux/Mac
# 或 venv\Scripts\activate  # Windows

# 安装依赖
pip install -r requirements.txt
```

### 2. 本地预览

```bash
mkdocs serve
```

访问 http://127.0.0.1:8000 查看网站

### 3. 构建网站

```bash
mkdocs build
```

生成的静态文件将在 `site/` 目录中。

## 自定义配置

### 主题配置
